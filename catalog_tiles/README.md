# Плитки отелей для каталога Meta

`render_tiles.py` рисует для каждого отеля из фида квадратную плитку 1080×1080 в стиле карточки
«Избранное» приложения Livin и пишет новый фид, где плитка стоит первой картинкой.

**Это рабочий прототип для бэкенда.** Логика проверена на настоящем фиде (см. ниже). Визуал
приблизительный: дизайн доводит плитку 1 в 1 до карточки «Избранное». Все размеры, отступы,
цвета и шрифты — в блоке «Макет» в начале скрипта и в методе `Renderer.render`. Можно взять
скрипт как есть, а можно переписать на своём стеке, сохранив правила из раздела
«Что обязательно сохранить».

Примеры: `examples_real_feed.png` — 12 плиток из настоящего фида.

Что на плитке:
- фото отеля (первое из фида) с закруглёнными углами;
- слева сверху плашка со звёздностью: N оранжевых звёзд (у приложения там рейтинг);
- справа сверху логотип Livin (`--logo`, PNG с прозрачным фоном), если передан;
- значок места + «Тип, Город»;
- название синим (обрезается многоточием);
- «от ₸82 711 за ночь» серым. Нет цены, 0 или не KZT — строки цены нет.

## Запуск в ночной сборке фида

```bash
pip install pillow
python3 render_tiles.py \
  --feed hotels.csv \
  --out-dir tiles/ \
  --base-url https://d260djxm8uty7r.cloudfront.net/feeds/meta/tiles/ \
  --out-feed hotels_branded.csv \
  --price-state price_state.json \
  --logo livin_logo.png \
  --col-kind category
```

Потом залить `tiles/` и `hotels_branded.csv` на CDN и отдавать Meta `hotels_branded.csv`
(или подменить им `hotels.csv`). Всё должно быть готово до загрузки в 07:00 по Алматы.

Колонки фида по умолчанию: `hotel_id`, `name`, `address.city`, `star_rating`, `base_price`,
`image[N].url`. Другие имена — флагами `--col-*`.

## Почему так устроено

- **Ссылка меняется только когда меняется картинка.** В имени файла хеш от фото, названия,
  города, звёзд, цены, логотипа и версии макета. Meta не скачивает заново файл по той же ссылке
  и притормаживает, если ссылки меняются каждую ночь без изменений картинки, поэтому дату
  в ссылку не добавляем и файлы не перезаписываем.
- **Повторно не рисует.** Если файл с таким хешем уже есть в `--out-dir`, он переиспользуется.
  Держите `tiles/` между запусками (или синхронизируйте с CDN).
- **Цена на плитке «липкая».** Нарисованная цена хранится в `price_state.json` (держать между
  запусками рядом с `tiles/`). Плитка перерисовывается, только если цена ушла из коридора:
  выросла больше чем на 10% (`--max-rise-pct`) или упала больше чем на 30% (`--max-drop-pct`).
  Новая цена рисуется точной, без округления. Нет цены сегодня — остаётся прежняя.
  Так большая часть плиток не меняется от ночи к ночи и Meta не качает их заново.
  `--no-price` убирает цену совсем.
- **Тип жилья** берётся из колонки `category` фида («Отель», «Апартаменты», «Курортный отель»…).
  Если название начинается с того же слова («Отель Rixos Borovoe»), оно убирается из названия,
  чтобы не было «Отель, Щучинск / Отель Rixos Borovoe».
- Ошибка скачивания фото не ломает фид: строка уходит с исходными фото, в stderr предупреждение.
- Шрифт Inter (SemiBold и Medium): кириллица, казахские буквы и ₸ есть. Путь можно задать
  `--font-semibold` / `--font-medium`.

Замер на 200 случайных строках настоящего фида (16 потоков, со скачиванием фото с cdn.worldota.net):
8,9 с, ~170 КБ на плитку. На весь фид (9 093) — около 7 минут и ~1,5 ГБ.

## Что обязательно сохранить при любой реализации

1. Плитка — `image[0].url`, исходные фото сдвигаются на +1 (всего не больше 20).
2. Имя файла плитки содержит хеш её содержимого; файл по существующей ссылке никогда
   не перезаписывается; дата/время в ссылке не используются.
3. Неизменившиеся плитки не перерисовываются; `tiles/` и `price_state.json` живут между запусками.
4. «Липкая» цена: коридор +10% / −30% от нарисованной, иначе перерисовать с текущей точной ценой.
5. Нет цены, 0 или валюта не KZT — строку цены не рисовать.
6. Нет звёздности — плашку звёзд не рисовать.
7. Ошибка с фото — строка уходит в фид с исходными фото, фид собирается в любом случае.
8. Файлы пишутся атомарно (tmp → rename), чтобы Meta не скачала недописанную картинку.
9. Всё готово и залито на CDN до загрузки фида в Meta в 07:00 по Алматы.

## Открытые вопросы к дизайну

- Звёзды у апартаментов: в фиде у части квартир стоит звёздность (например 5★) — рисовать ли.
- Что ставить на место цены, если её нет (сейчас пусто).
- Логотип Livin справа сверху (на месте сердечка в приложении) — нужен PNG с прозрачным фоном.
- Шрифт приложения вместо Inter, если он другой.

## Что поменять при смене макета

Поднять `TEMPLATE_VERSION` в начале скрипта — все плитки получат новые ссылки и перерисуются.
